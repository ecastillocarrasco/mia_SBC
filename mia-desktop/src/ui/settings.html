Micrófono y frase de activación

El modo elegido en Configuración también aparece en el chat. La conversación no se inicia por sí sola al abrir la aplicación: se activa expresamente desde el chat. «Desactivado» libera el dispositivo de captura y desactiva los comandos por voz. El comando para cerrar solicita confirmación. Los comandos se reconocen con Vosk local y no se envían al chat. Voz V0.3: Vosk para comandos y faster-whisper para dictado. Instala previamente los modelos con INSTALAR_VOZ_LOCAL.cmd (descarga inicial voluntaria). Mostrar mIA con la frase o el atajo nunca inicia una transcripción. El modo se elige desde el propio chat. Whisper no entrega una puntuación de confianza equivalente a los reconocedores clásicos. Con envío automático desactivado, siempre podrás revisar el texto antes de enviarlo.

Backend y voz original de mIA

HTTP únicamente en localhost. Para otro equipo, utilizar HTTPS. No se guardan claves de ElevenLabs aquí. El backend debe ofrecer /api/mia/voice. Un HTTP 503 es un error del servicio de voz: revisa los registros del backend o sus credenciales de ElevenLabs. El respaldo local no usa la voz original.

Diagnóstico de voz y aplicación

Comprueba el motor Vosk + faster-whisper local. Instala los componentes con INSTALAR_VOZ_LOCAL.cmd desde la raíz de mIA Desktop. Ningún audio se envía a Internet.

Los registros técnicos no guardan voz, transcripciones, preguntas, respuestas, nóminas ni datos de empleados.
