# 19 - Catálogo de Capacidades de mIA

## Guía para usuarios finales

Este catálogo describe todo lo que puedes pedirle a mIA hoy. Para cada área, se incluyen ejemplos de preguntas reales que puedes hacer con tus propias palabras.

---

## Lo que mía NO puede hacer hoy

- Crear, modificar o eliminar datos en SharePoint (solo lectura)
- Aprobar solicitudes de vacaciones
- Publicar o modificar turnos
- Enviar recordatorios futuros ni avisos programados
- Consultar datos de fichajes (control de presencia real)
- Consultar datos de finanzas, contabilidad o presupuestos
- Consultar datos de evaluaciones de desempeño
- Consultar el calendario laboral o festivos del convenio
